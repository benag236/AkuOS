AkuOS Security

Security Practices

AkuOS uses basic security practices to protect app data and reduce exposure of sensitive configuration.

Dependency Updates

Dependencies are updated regularly to pick up security patches and maintenance fixes.

Hosting Security

AkuOS relies on Render for hosting infrastructure security, including platform-level protections, deployment isolation, and operational safeguards.

Secrets Management

Secrets such as API keys, database URLs, encryption keys, and session secrets are configured with environment variables.

No Credentials in Code

Bank credentials and production secrets are not stored in the codebase. Bank login credentials are handled by Plaid during connection.

Account Protection

  • User passwords are stored as password hashes.
  • Session cookies are configured with secure defaults for app access.
  • Financial data is scoped to the signed-in user.
