AkuOS Security

Access Control Policy

This policy defines how AkuOS restricts administrative and production access, handles credentials, and reviews privileges.

Authorized admins only Environment secrets Least privilege

Purpose and Scope

This policy applies to AkuOS production systems, administrative access, infrastructure accounts, source code, secrets, and operational tools used to provide and maintain the service.

Authorized Administrators

Only authorized administrators may access AkuOS production systems, infrastructure dashboards, deployment settings, databases, or production configuration.

Least Privilege

Access is limited using least privilege principles. Administrators should receive only the permissions needed to perform their assigned operational or support responsibilities.

Secrets Management

  • Secrets are stored in environment variables only.
  • Production credentials must not be stored in source code.
  • Secrets should not be printed in logs, exposed in templates, or shared through unsecured channels.

Source Code Controls

No production credentials, API secrets, database URLs, encryption keys, or session secrets should be committed to the AkuOS source repository.

Admin Authentication

Authentication is required for admin access. Administrative workflows and maintenance actions should be restricted to authenticated and authorized users.

Infrastructure Restrictions

Production infrastructure access is restricted to authorized administrators and should be managed through approved provider controls, such as Render account and service permissions.

Access Reviews

Access reviews are performed periodically to confirm that production, infrastructure, and administrative access remains appropriate and unnecessary access is removed.

Monitoring and Changes

Administrative changes and security-relevant access events should be logged or reviewed where practical, without intentionally exposing secrets or sensitive financial details.

Contact

Access control questions or security concerns can be sent to {{ contact_email }}.

This access control policy supports AkuOS security practices and should be reviewed as administrator workflows, hosting configuration, and production infrastructure evolve.
