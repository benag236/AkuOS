How AkuOS Works

A simple guide to setting up AkuOS, cleaning transactions, and making the app learn from your decisions.

Start with the basics

AkuOS works best when you add a small set of transactions first, clean the categories, then let rules and merchant memory reduce future cleanup.

1. Add data Connect a bank with Plaid or upload transactions in Import Center.
2. Review transactions Fix missing categories, duplicates, and rows that need attention.
3. Automate cleanup Use bulk edit, Merchant Memory, and Rules for repeated patterns.
4. Track progress Use Dashboard, Budgets, Subscriptions, and Goals once data is clean.

Getting Started Workflow

Follow these steps before adding a lot of real data.

1
Connect your bank

Use Accounts to link bank accounts through Plaid for ongoing transaction sync.

Example: Link checking and credit card accounts first.
2
Or upload transactions

Use Import Center when you prefer CSV, PDF, or pasted statement data.

Example: Upload last month’s credit card statement.
3
Review and clean

Use Transactions to fix missing categories, duplicates, and low-confidence rows.

Example: Filter to Missing Category and bulk update similar rows.
4
Fix categories faster

Use bulk edit, Rules, or Merchant Memory to avoid repeating manual edits.

Example: Remember Starbucks as Food or Coffee.
5
Track spending

Use Dashboard for safe-to-spend, cash flow, recent activity, and trends.

Example: Check safe-to-spend before discretionary purchases.
6
Set budgets

Use Budgets to set monthly category limits and spot overspending early.

Example: Set Groceries to $500 for the month.
7
Improve automation

Use Rules and Merchant Memory after cleanup so AkuOS learns your habits.

Example: Create a rule for payroll deposits.

Feature Breakdown

What each section does, when to use it, and one concrete example.

Dashboard
What it does

Summarizes cash flow, safe-to-spend, upcoming bills, trends, and recent activity.

When to use it

Use it for a quick daily or weekly financial check-in.

Example: Safe-to-spend estimates what is left after expected bills and goals.
Transactions
What it does

Searches, filters, edits, bulk-updates, and reviews every transaction.

When to use it

Use it when transactions need cleanup or you want to find specific activity.

Example: Select 20 grocery transactions and bulk set category to Groceries.
Accounts
What it does

Tracks manual accounts, Plaid-linked accounts, balances, debts, and account details.

When to use it

Use linked accounts for bank sync and manual accounts for cash or offline balances.

Example: Add a manual Cash Wallet, then link checking through Plaid.
Import Center
What it does

Parses CSV, PDF, or pasted statements and previews rows before import.

When to use it

Use it for backfilling history or when you do not want Plaid sync.

Example: Review duplicates and category guesses before final import.
Budgets
What it does

Compares monthly category spending against limits you set.

When to use it

Use it after transactions are categorized enough to make category totals reliable.

Example: Cap Entertainment at $150 and watch progress through the month.
Subscriptions
What it does

Detects recurring merchants and combines them with manually added upcoming payments.

When to use it

Use it to audit fixed monthly costs and upcoming recurring charges.

Example: Spot streaming services or yearly renewals before they hit.
Rules
What it does

Applies structured matching logic for categories, display names, tags, and skipped rows.

When to use it

Use Rules for patterns broader than one merchant or for advanced automation.

Example: If description contains Payroll, categorize as Income.
Merchant Memory
What it does

Remembers a simple merchant-to-category decision from your manual edits.

When to use it

Use it when one merchant should always use the same category.

Example: When AkuOS sees Target again, use Shopping.
Goals & Wealth
What it does

Tracks goals, allocations, net worth, planning, and longer-term money decisions.

When to use it

Use it after accounts and balances are set up.

Example: Allocate checking surplus toward an emergency fund goal.

Key Concepts

Fast explanations for the areas that sound similar but behave differently.

Plaid vs Import Center

Plaid is best for ongoing sync. Import Center is best for controlled uploads, history backfill, and reviewing rows before they affect your ledger.

Manual vs Linked Accounts

Manual accounts are balances you manage yourself. Linked accounts come from Plaid and can refresh bank transactions and balances.

Categories & Subcategories

Categories are broad spending buckets like Food or Transportation. Subcategories add detail only when a category needs it.

Rules vs Merchant Memory

Merchant Memory learns one merchant at a time. Rules handle broader patterns, special cleanup, skipped rows, and advanced matching.

Bulk Edit

Bulk edit lets you select many transactions and apply one category, subcategory, memory rule, or reviewed status in a single action.

Safe to Spend

Safe to spend estimates what remains after expected bills, goals, recurring costs, and recent cash flow are considered.

Common Questions

Short answers for the decisions that usually cause confusion.

General
What is the best way to start using AkuOS?
Start with one account and a small date range. Import or sync transactions, clean categories, then add budgets once the data looks trustworthy.
Do I need to connect a bank to use the app?
No. You can use manual accounts and Import Center. Plaid is useful for ongoing sync, but imports work well for controlled setup.
What happens if I delete all my data?
Financial data for your profile is removed, including accounts, transactions, budgets, goals, imports, rules, and memory. Your login account remains.
Can I undo changes?
Some actions include undo, such as recent allocations and bulk transaction edits. Destructive actions like Delete All Data require confirmation and should be backed up first.
Data & Sync
Should I use Plaid or Import Center?
Use Plaid for ongoing sync. Use Import Center for historical backfill, offline review, or when you prefer approving rows before they enter the ledger.
Why don’t my balances match my bank exactly?
Balances can differ because pending transactions, manual edits, imports, and account timing may not match the bank’s live ledger exactly.
How often does data update?
Plaid data updates when you refresh or when sync is triggered. Imported files update only when you upload and commit a review.
Are pending transactions included?
Pending Plaid transactions are skipped until they post. This reduces duplicate rows and changing amounts.
Categorization
Why are some transactions uncategorized?
AkuOS marks rows for review when no strong rule, memory, import value, or built-in hint matches the transaction.
How do I fix categories faster?
Use bulk edit for batches, Merchant Memory for one merchant, and Rules for repeated text patterns across many merchants.
Does editing a transaction create a rule automatically?
Manual edits can remember merchants and apply to similar transactions. Advanced rules are still best when you need broader or more exact matching.
What is the difference between Rules and Merchant Memory?
Merchant Memory is simple: this merchant gets this category. Rules are stronger: match text, direction, tags, display names, or skip behavior.
When should I use Rules vs Merchant Memory?
Use Memory for “Starbucks equals Food.” Use Rules for “anything containing Payroll is Income” or “skip statement credits.”
Transactions
Can I edit multiple transactions at once?
Yes. Select rows on Transactions and use the bulk action bar for category, subcategory, merchant memory, or reviewed status.
How does bulk edit work?
Bulk edit applies the same change to selected rows and updates the visible list. The most recent bulk edit can be undone.
How do I find a specific transaction quickly?
Use search plus filters for account, date, category, status, tag, or source. Missing Category and Missing Detail are quick cleanup filters.
Accounts
What is the difference between manual and linked accounts?
Manual accounts are edited by you. Linked accounts come from Plaid and can refresh balances and transactions from the bank connection.
Can I track cash or offline accounts?
Yes. Add a manual asset account for cash, savings jars, offline balances, or anything Plaid does not cover.
What happens if I disconnect a bank?
The live Plaid connection is removed. Existing transactions may remain in AkuOS unless you delete the account or data separately.
Importing
What happens during import review?
AkuOS parses rows, detects categories, flags duplicates, shows a summary, and lets you approve or edit rows before final import.
How are duplicates handled?
Exact duplicates are skipped. Possible duplicates are shown for review so you can decide before importing.
Can I re-import the same file?
Yes, but duplicate detection should skip rows that already exist or appear again within the same import.
Budgets
How do budgets work?
Budgets compare categorized monthly spending against the category limits you set.
What happens if I go over budget?
AkuOS highlights the category as over budget so you can adjust spending or revisit the limit.
Are budgets monthly or custom?
Budgets are monthly category limits. Custom planning belongs in Goals & Wealth.
Subscriptions
How are subscriptions detected?
AkuOS looks for recurring merchant timing, similar amounts, subscription-like categories, and upcoming recurring payments.
Can I manually add subscriptions?
Yes. Add recurring upcoming payments to track subscriptions or bills that do not appear clearly in transaction history yet.
Automation
How does the system learn my habits?
Manual edits can create merchant memory, similar-transaction updates, and learned rules that improve future categorization.
Will the app improve over time?
Yes. The more you review categories and save memory or rules, the fewer future transactions should need manual cleanup.
Security
Is my data secure?
AkuOS keeps financial records scoped to your profile and avoids exporting passwords or secrets in backups.
Does AkuOS store bank login credentials?
No. Bank login happens through Plaid. AkuOS stores connection tokens, not your bank username or password.
What data is actually saved?
The app saves accounts, transactions, categories, memory, rules, budgets, goals, upcoming payments, imports, and preference settings.

Advanced Details

Use these once the basics are working and you want tighter control over automation, imports, and data safety.

Rules are for repeatable patterns

Use rules when a merchant name is not enough, such as matching payroll text, transfer wording, tags, transaction direction, or cleanup behavior.

Merchant Memory is intentionally simple

Memory answers one question: “When I see this merchant again, what category should it use?” It is best for common merchants you edit repeatedly.

Import review protects your ledger

Before final import, AkuOS previews new rows, possible duplicates, date range, accounts affected, and detected categories so you can catch issues early.

Undo is for recent bulk cleanup

The latest bulk transaction edit can be reversed, which helps when a category or reviewed status was applied to the wrong batch.

Backups exclude secrets

Export backups focus on user financial data like accounts, transactions, rules, memory, budgets, goals, subscriptions, and settings, not passwords or secrets.

Plaid credentials stay with Plaid

Bank login credentials are handled by Plaid. AkuOS stores connection data needed for sync, not your bank username or password.
