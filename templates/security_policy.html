AkuOS Security

Information Security Policy

This policy describes the safeguards AkuOS uses to protect customer financial data, manage secrets, control access, and respond to security concerns.

Customer financial data HTTPS/TLS Plaid + Render

Purpose and Scope

This policy applies to AkuOS application systems, hosted infrastructure, data handling practices, third-party integrations, and administrative access used to provide the service.

Financial Data Protection

  • Customer financial data is used only to provide AkuOS features such as dashboards, transactions, budgets, rules, imports, goals, and account sync.
  • Financial records are scoped to the signed-in user and should not be exposed across user accounts.
  • Passwords and secrets are not included in data exports.

HTTPS and TLS

AkuOS is intended to be served over HTTPS/TLS in production so data is encrypted in transit between users, the app, and supported service providers.

Secrets Handling

Production secrets, API keys, database URLs, encryption keys, and session secrets are configured through environment variables. Secrets should not be committed to the codebase or logged.

Least Privilege

Access to systems, configuration, and financial data should be limited to the minimum access needed to operate, support, and secure AkuOS.

Access Control

  • User access requires authentication.
  • Administrative and maintenance actions should be restricted to authorized users.
  • User data queries should remain scoped to the current user whenever financial records are accessed.

Third-Party Providers

AkuOS uses Plaid for bank connections and Render for hosting. Plaid handles bank credential collection, and Render provides hosted infrastructure controls.

Logging and Monitoring

Application logging should support troubleshooting, security review, and operational monitoring without intentionally recording secrets, bank credentials, or unnecessary sensitive financial details.

Dependency Updates

Dependencies should be reviewed and updated regularly so security fixes, compatibility updates, and maintenance patches are applied in a timely way.

Incident Response

If a security incident is suspected, AkuOS will investigate, reduce exposure, preserve relevant logs where appropriate, and communicate with affected users when required.

Retention and Deletion

Data is stored only as long as necessary to provide the service. Users can request deletion at any time, and unused data may be periodically removed. See the Privacy Policy for related details.

Contact

Security questions, concerns, or reports can be sent to {{ contact_email }}.

This policy is a practical operating statement for AkuOS and should be reviewed as the app, infrastructure, and third-party integrations evolve.
